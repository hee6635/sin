### 메모 입력 시 키보드에 가려지는 문제 (①+② 둘 다)

#### ① 기본 수정
- [x] MainActivity 인셋 처리에 키보드(IME) 높이 포함 → 키보드가 올라오면 WebView가 그만큼 줄어들게

- [x] 입력칸에 포커스가 가면 그 줄을 키보드 위로 자동 스크롤 (`visualViewport` resize 때도 다시 맞춤)

#### ② 메모 "채팅 입력창" 방식
- [x] 메모 입력칸을 시트 맨 아래(키보드 바로 위)에 고정, [추가] 누르면 위 목록에 한 줄씩 쌓임
