### 개인 메모 / 가족 메모 구분 — 시안: design/ui-memo.png (구조), design/ui-memo-color.png (색)
- [ ] 가족 메모 기본 색 = **보라** (#7b5cf0 / 바탕 #f3f0ff) — 빨강(휴무·일요일)·파랑(토요일)·초록(오늘)과 안 겹침
- [ ] 설정 > "메모 색"에서 가족 메모 색·개인 메모 색을 바꿀 수 있게 (근무타입 색 고르기와 같은 팔레트, 미리보기, 기본값으로 되돌리기)
      · 고른 색에서 연한 바탕·테두리·글자색 자동 계산, 다크 모드도 자동
      · 빨강 계열을 고르면 "휴무 색과 비슷해요" 안내
      · 색 설정은 내 폰에만 저장 (가족마다 따로 고를 수 있음)
- [ ] 달력 칸: 가족 메모 = 보라 바탕 흰 글씨 + ♥, 개인 메모 = 연회색 바탕 + 🔒 (가족 메모를 위에), 아래에 범례 한 줄
- [ ] 날짜 화면: "전체 / ♥ 가족 / 🔒 개인" 탭(개수 표시), 가족 메모 묶음 → 개인 메모 묶음 순서
- [ ] 가족 메모 카드: 연보라 바탕 + 왼쪽 보라 줄 + 쓴 사람 표시(아내 / 나), 시각
- [ ] 개인 메모 카드: 회색 바탕, 오른쪽 "♥ 가족에게" 버튼으로 바로 가족 메모로 전환
- [ ] 쓰기 전: 입력창 왼쪽 "🔒 나만 / ♥ 가족" 스위치, 가족이면 입력창·보내기 버튼 보라 + "가족 모두에게 보여요 · 알림이 가요" 안내
- [ ] 쓴 후: 메모를 길게 누르면 메뉴 (가족 메모로 바꾸기 / 나만 보기로 바꾸기 / 수정 / 다른 날로 옮기기 / 삭제)
- [ ] 내가 쓴 가족 메모만 "나만 보기"로 되돌릴 수 있음, 남이 쓴 가족 메모는 수정·전환 불가(호스트는 삭제만)
- [ ] (2차에서 연결) 가족 메모로 바꾸면 Firebase 업로드 + 가족에게 알림, 나만 보기로 바꾸면 서버에서 삭제

### 메모 입력 시 키보드에 가려지는 문제 (①+② 둘 다)

#### ① 기본 수정
- [ ] MainActivity 인셋 처리에 키보드(IME) 높이 포함 → 키보드가 올라오면 WebView가 그만큼 줄어들게
      (`WindowInsetsCompat.Type.ime()` 를 bottom 패딩에 반영, 안드로이드 15 edge-to-edge 대응)
- [ ] 입력칸에 포커스가 가면 그 줄을 키보드 위로 자동 스크롤 (`visualViewport` resize 때도 다시 맞춤)
- [ ] 키보드가 떠 있을 때 날짜 시트 높이를 남은 공간에 맞추고, 시트 머리(날짜·닫기)는 고정

#### ② 메모 "채팅 입력창" 방식
- [ ] 메모 입력칸을 시트 맨 아래(키보드 바로 위)에 고정, [추가] 누르면 위 목록에 한 줄씩 쌓임
- [ ] 목록의 메모를 누르면 입력창으로 내려와 수정 (수정 중 표시 + 취소)
- [ ] 목록 줄마다 📌 공유 / 🗑 삭제 유지, 추가 직후 목록 맨 아래로 스크롤

### 백업: 구글 드라이브 (사용자 본인 드라이브의 앱 전용 숨김 폴더)
- [ ] 준비(사용자): Google Cloud 프로젝트(나중에 Firebase 와 같은 프로젝트로 씀)에서 Drive API 켜기 + OAuth 동의 화면 + 안드로이드 OAuth 클라이언트(패키지 com.eonjeswieo.app + 고정 서명 키 SHA-1)
      · 출시 전 테스트는 "테스트 사용자"로 바로 가능, 공개 출시 때 구글 앱 확인이 필요할 수 있음
- [ ] 네이티브 구글 로그인(Credential Manager) + 드라이브 권한(drive.appdata) → 같은 계정이면 새 폰에서 바로 복원
      · 이 로그인은 2차에서 Firebase 구글 로그인과 그대로 이어서 씀
- [ ] 백업은 **2개만 유지**: 최신 + 직전 1개 (새로 백업하면 가장 오래된 것 자동 삭제), 옵션 없음
      · 실수로 지운 상태가 자동 백업으로 덮이는 것 대비 → 복원 화면에 "직전 백업으로 복원"도 표시
- [ ] 자동 백업: 앱에서 데이터가 바뀌고 하루 1번 (와이파이·인터넷 있을 때), "지금 백업하기" 버튼
- [ ] 복원 화면: 백업 날짜·근무·메모 개수 보여주고 복원 (복원 전 확인 창), 복원은 전부 무료 (광고 없음)
- [ ] 내용: 개인 메모·알람·설정·근무타입 + 근무표 전체 사본 (가족 공유 데이터는 Firebase 에도 따로 있음)
- [ ] 안드로이드 기본 자동 백업(allowBackup)도 유지 → 폰 교체 때 한 번 더 안전망
- [ ] 기존 "백업 파일 만들기/불러오기"(파일 공유)는 고급 기능으로 남김

## 2차 · 가족이 함께 (Firebase)

### ★ 가족 실시간 공유 (Firebase) — 앱의 핵심 기능 · 상세 설계: docs/firebase-design.md
#### 준비 (사용자가 할 일)
- [ ] Firebase 프로젝트 만들기, 안드로이드 앱 등록(패키지 com.eonjeswieo.app), google-services.json 전달
- [ ] Authentication(익명 + 구글 로그인), Firestore 켜기
- [ ] 앱이 꺼져 있을 때 알림까지 받으려면 Blaze 요금제(무료 사용량 안에서는 0원, 카드 등록 필요) → Cloud Functions + FCM
#### 구조
- [ ] 가족방(family) 하나에 근무표 주인(호스트) + 가족 여러 명, 초대 코드(유효기간·1회용)로 참여
- [ ] Firestore 실시간 리스너: 근무 변경·메모·가족 메모·근무 요청·이번 달 메모가 상대 폰에 즉시 반영
- [ ] 오프라인에서 고친 것은 연결되면 자동 업로드 (Firestore 오프라인 캐시)
- [ ] 보안 규칙: 가족방 구성원만 읽기/쓰기, 게스트는 근무표 직접 수정 불가(요청만)
- [ ] 처음 연결할 때 지금 폰에 있는 데이터를 서버로 옮기기
- [ ] 앱이 꺼져 있어도 푸시 알림: "아내가 24일에 메모를 남겼어요", "16일 근무 요청이 수락됐어요"
#### 함께 넣을 것
- [ ] 누가 언제 무엇을 바꿨는지 기록 (변경 내역 목록, 달력 칸에 작은 표시)
- [ ] 읽음 표시: 상대가 메모·요청을 확인했는지
- [ ] 구성원 권한: 편집 가능 / 보기만, 내보내기, 초대 코드 다시 만들기
- [ ] 부부 모두 교대근무일 때: 두 사람 근무표 겹쳐 보기 + "같이 쉬는 날" 강조
- [ ] 알림 종류별 켜고 끄기 (메모 / 근무 변경 / 요청)
- [ ] 연결 상태 표시 (동기화됨 / 오프라인 / 동기화 중)

### 가족 초대 방식 — 시안: design/ui-invite.png
- [ ] 설정 › 가족 연결 (호스트): 가족 목록(호칭·마지막 확인 시각·권한), 남은 자리 "가족 2/3명", [＋ 가족 초대하기], 공유 설정(근무표 공유, 가족 메모 알림)
- [ ] 가족 초대하기: 호칭 입력, 권한 선택(메모·요청 보내기 / 보기만) → 8자리 코드(헷갈리는 문자 제외, XXXX-XXXX), 7일 유효, QR 코드
      · 카카오톡으로 보내기(공유 시트) · 링크 복사 · 코드 다시 만들기(이전 코드 무효)
      · 초대 링크를 누르면 앱이 열리고 코드 자동 입력 (앱 없으면 설치 안내 페이지)
- [ ] 가족 폰 첫 화면: "내 근무표 만들기" / "초대 코드가 있어요" 두 갈래
- [ ] 코드 입력: 8칸 + 붙여넣기 → 확인되면 "○○님의 근무표 · 4조2교대 C조 · 가족 N명" + 7일 미리보기 → 내 호칭 → 참여하기
      · 틀린 코드 / 만료 / 자리 없음 안내, 여러 번 틀리면 잠시 대기
- [ ] 참여하면 호스트에게 푸시 "아빠님이 가족 근무표에 참여했어요"
- [ ] 가족 관리 메뉴: 호칭 바꾸기, 권한 바꾸기, 가족에서 내보내기 / 가족 쪽에는 "가족에서 나가기"
- [ ] 권한: 근무표는 호스트만 수정. "메모·요청" = 가족 메모 쓰기 + 근무 변경 요청, "보기만" = 읽기만 (규칙으로 강제)

## 3차 · 나중에 (써 보고 반응 보고)

### 홈 화면 위젯 (3차: 2칸 · 한 달 먼저, 1칸 · 7일은 그다음) — 시안: design/ui-widgets.png (참고: 보내준 "한 달 / 1일 / 7일 위젯" 화면)
#### 위젯 4종
- [ ] 1칸: 오늘 날짜·요일 + 근무 동그라미 + 메모 1줄
- [ ] 2칸: 오늘 + 내일 나란히 (+ 다음 알람 시각 한 줄)
- [ ] 7일: 오늘부터 7일 (또는 "요일 고정"이면 이번 주 일~토)
- [ ] 한 달: 달력 전체 + 메모, 공휴일 이름, 오늘 테두리, ‹ › 달 넘기기, 톱니(위젯 설정)
#### 위젯마다 설정 화면 (위에 미리보기, 아래 설정, 맨 아래 "위젯 사용" 버튼)
- [ ] 배경 투명도 슬라이더, 배경 색 (흰색 / 검정 / 다크 모드 따라가기)
- [ ] 메모 크기 · 날짜·요일 크기 · 근무 크기 (1 / 2 / 3)
- [ ] 한 달: 날짜 구분선 보이기/감추기, 6주 고정, 메모 표시, 대근 표시, 음력 표시, 변경 근무 강조
- [ ] 7일: 요일 고정
#### 동작
- [ ] 근무 글자·색은 앱의 근무타입 그대로 (영문 D/N/H 대신 주/야/휴, 직접 만든 근무 색)
- [ ] 위젯의 날짜를 누르면 앱이 그 날짜 화면으로 열림
- [ ] 앱에서 근무·메모를 바꾸면 위젯 바로 갱신, 자정에 자동으로 날짜 넘김 (새로고침 버튼은 빼기)
- [ ] 앱이 위젯에 지난달~3개월 뒤까지 근무·메모·공휴일을 넘겨줌 (그 밖의 달은 "앱을 열어주세요")

### 알람 (3차)
- [ ] 끄기 미션은 **수학 문제부터** (문제 수·난이도), 흔들기·순서 누르기·카드 짝 맞추기는 반응 보고
- [ ] 공휴일 건너뛰기: 알람마다 켜고 끄기 (회사 휴무일 포함 선택)
- [ ] 출근 전 미리 알림: 전날 밤(시간 선택)에 "내일 주간 · 05:50 알람" 알림

### 그 밖의 기능 (3차)
- [ ] 음력 날짜 표시: 달력 칸에 음력 1일·15일 "음9.1" (설정에서 켜고 끄기)
- [ ] 근무 교대 기록: 날짜 화면에서 "누구와 · 무슨 근무를 바꿨는지" 남기기, 달력에 표시, 월별 목록
- [ ] 수당 세분화: 대근 시급 + 야간수당·휴일수당 시급 따로, 이번 달 예상 수당 내역
- [ ] 광고 · 구독 (쓰는 사람이 늘면): 하루 무료 횟수, 보상형 광고, 월 구독
