# 나중에 한꺼번에 만들 것

## 메모 입력 시 키보드에 가려지는 문제 (①+② 둘 다)

### ① 기본 수정
- [ ] MainActivity 인셋 처리에 키보드(IME) 높이 포함 → 키보드가 올라오면 WebView가 그만큼 줄어들게
      (`WindowInsetsCompat.Type.ime()` 를 bottom 패딩에 반영, 안드로이드 15 edge-to-edge 대응)
- [ ] 입력칸에 포커스가 가면 그 줄을 키보드 위로 자동 스크롤 (`visualViewport` resize 때도 다시 맞춤)
- [ ] 키보드가 떠 있을 때 날짜 시트 높이를 남은 공간에 맞추고, 시트 머리(날짜·닫기)는 고정

### ② 메모 "채팅 입력창" 방식
- [ ] 메모 입력칸을 시트 맨 아래(키보드 바로 위)에 고정, [추가] 누르면 위 목록에 한 줄씩 쌓임
- [ ] 목록의 메모를 누르면 입력창으로 내려와 수정 (수정 중 표시 + 취소)
- [ ] 목록 줄마다 📌 공유 / 🗑 삭제 유지, 추가 직후 목록 맨 아래로 스크롤

## 동료근무 화면 다시 그리기 — 확정 시안: design/ui-colleague.png (라이트/다크)
- [ ] 상단을 근무일정 탭과 같은 모양으로: 가운데 ‹ 2026.10 › + "근무 이름 C조", 오른쪽 "오늘"
- [ ] 표: 왼쪽 날짜칸 "1.목" 형식 (토 파랑 / 일·공휴일 빨강, 공휴일은 분홍 배경), 세로·가로 얇은 줄
- [ ] 내 조 열 전체를 연한 노랑 배경으로, 머리줄 "A조 B조 C조 D조" 고정(스크롤해도 위에 남음)
- [ ] 오늘 줄은 초록 위아래 선 + 연한 초록 배경, 들어오면 오늘 줄로 자동 스크롤
- [ ] 근무 동그라미는 근무일정 탭과 같은 색·굵기 (사용자 근무타입 색 반영)
- [ ] 조 순서 바로잡기: 지금 계산은 A조와 B조가 뒤바뀜.
      참고 화면 기준(C조=나) A조=내 근무 +6일, B조=+4일, D조=+2일 → 이걸 기본값으로
- [ ] 설정에 "조별 근무 맞추기"(조마다 하루씩 앞/뒤로 밀기) 추가 → 회사마다 다른 조 순서 대응
- [ ] 머리줄의 조 이름을 누르면 "내 조"로 바꾸기, 날짜를 누르면 그 날 근무일정 화면으로 이동

## 알람 설정 화면 다시 그리기 (보내준 참고 화면 "알람설정")
- [ ] 시트 대신 전체 화면: 상단 ‹ 뒤로 + "알람설정", 항목을 한 줄씩 (이름 왼쪽 / 값 오른쪽)
- [ ] 근무타입: 오른쪽 동그라미, 누르면 근무타입 목록(사용자 근무타입 + 매일)에서 고르기
- [ ] 알람일: 전날 / 다음날 / 당일 (다음날 추가 — 야간 끝나고 다음날 아침 알람 등)
- [ ] 알람시간: "오전 05:50" 크게, 누르면 시간 선택
- [ ] 알람반복 스위치: 끄면 다음 한 번만 울리고 자동으로 꺼짐
- [ ] 알람 이름: 비어 있으면 "설정 안됨"
- [ ] 알람종류: 소리 / 진동 / 무음 (소리·진동은 같이 켤 수 있음, 무음은 화면만)
- [ ] 볼륨 슬라이더: 알람마다 따로 (네이티브에서 그 알람만 해당 볼륨으로 재생)
- [ ] 알람음 선택: 폰에 있는 알람음 목록에서 고르기 (안드로이드 알람음 선택 창), 미리 듣기
- [ ] 맨 아래 🗑 삭제

## 알람 끄기 미션 (알람마다 "미션 없음 / 수학 / 흔들기 / 순서 / 짝 맞추기" 선택)
- [ ] 수학 문제: "27 + 46 = ?" 맞혀야 꺼짐 (문제 수·난이도 선택)
- [ ] 흔들기: 폰을 정해진 횟수(기본 20번) 흔들어야 꺼짐
- [ ] 순서 누르기: 흩어진 숫자 1~9를 순서대로 눌러야 꺼짐
- [ ] 카드 짝 맞추기: 뒤집힌 카드 짝을 모두 맞춰야 꺼짐
- [ ] 미션 중에도 소리는 계속, 미션 화면에서 "다시 울림"은 가능

## 알람 추가 기능
- [ ] 점점 커지는 소리: 작게 시작해 30초 동안 정한 볼륨까지
- [ ] 다시 울림 설정: 간격(5·10·15분)·최대 횟수(예: 3번)
- [ ] 공휴일 건너뛰기: 알람마다 켜고 끄기
- [ ] 출근 전 미리 알림: 전날 밤(시간 선택)에 "내일 주간 · 05:50 알람" 알림

## 그 밖의 추가 기능
- [ ] 홈 화면 위젯: "오늘 야간 · 내일 휴무 · 다음 알람" (안드로이드 위젯, 자정에 갱신)
- [ ] D-day: 다음 휴무까지 N일, 직접 넣는 기념일·연차 D-day (상단 왼쪽 버튼 → D-day 목록)
- [ ] 음력 날짜 표시: 달력 칸에 음력 1일·15일 "음9.1" (설정에서 켜고 끄기)

- [ ] 수당 세분화: 대근 시급 + 야간수당·휴일수당 시급 따로, 이번 달 예상 수당 내역
