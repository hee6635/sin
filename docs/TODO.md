### 메모 입력 시 키보드에 가려지는 문제 (①+② 둘 다)

#### ① 기본 수정
- [x] MainActivity 인셋 처리에 키보드(IME) 높이 포함 → 키보드가 올라오면 WebView가 그만큼 줄어들게

- [x] 입력칸에 포커스가 가면 그 줄을 키보드 위로 자동 스크롤 (`visualViewport` resize 때도 다시 맞춤)

#### ② 메모 "채팅 입력창" 방식
- [x] 메모 입력칸을 시트 맨 아래(키보드 바로 위)에 고정, [추가] 누르면 위 목록에 한 줄씩 쌓임

- [ ] 게스트 달력: 근무 동그라미 대신 날짜 숫자에 휴무 빨간 동그라미(주말·공휴일 휴무는 노란 테두리), 칸 아래는 전부 메모(2줄 줄바꿈), 근무 요청은 주황, 날짜 누르면 메모 시트
- [ ] ① 실시간 상태 · 출퇴근 시간 · 상태 이모티콘 → 다음 묶음 ③ · ④ 로 옮김. 2차: 가족 폰에 실시간 반영 + 퇴근 알림 푸시
- [ ] ③ 응원 한마디
      · 근무 시작 전후로 게스트 홈에 버튼: ☕ 수고해 / 💪 힘내 / 🍗 야식 먹어 / ❤️ 사랑해 (+ 직접 쓰기 한 줄)
      · 근무자 폰에 "딸이 응원을 보냈어요 ☕" 알림, 근무 중 방해 안 되게 조용한 알림
      · 받은 응원은 🔔 가족 소식에 쌓이고, 근무자가 "고마워 👍" 한 번에 답장
      · 하루에 같은 사람이 같은 응원은 1번만 (알림 폭탄 방지)
      · 응원 버튼 바꾸기 (게스트 각자): 이모티콘 + 짧은 문구 최대 6개, 추가 · 삭제 · 순서 바꾸기, 기본값으로 되돌리기
        (예: 🍜 라면 먹어 / 😘 보고싶어 / 🧤 추우니까 따뜻하게)
- [ ] 근무 변경 즉시 알림: "아빠가 17일(토)을 휴무로 바꿨어요" (홈 상단 한 줄에도)
- [ ] (위젯, 3차와 함께) 게스트 위젯: 오늘 상태(근무 중/자는 중) + 같이 쉬는 날

### 2차에서 1차 기능과 이어 붙일 것
- [ ] 가족(게스트) 폰에는 **백업 · 복원 메뉴 숨기기**: 근무표 · 가족 메모 · 월 메모는 근무자(호스트) 가족방에 저장되니 따로 백업할 게 없음
      · 게스트 개인 것(나만 보는 메모 · 응원 버튼 · 알림 설정)은 Firebase 내 계정 칸에 자동 저장 → 폰을 바꿔도 같은 구글 계정으로 들어오면 그대로
      · 게스트 설정 화면엔 "백업" 대신 "☁️ 구글 계정으로 자동 저장 중 (xxx@gmail.com)" 한 줄만
      · 호스트는 드라이브 백업 그대로 유지 (가족방이 지워지거나 실수로 바꿨을 때 되돌리는 안전장치)
- [ ] 🔔 가족 소식을 실제 가족 데이터·푸시로 연결
- [ ] 가족 메모 · 월 메모(가족) · D-day(가족 공유) · 회사 휴무일을 Firestore 와 동기화
- [ ] 구글 로그인(1차 드라이브 백업용)을 Firebase 계정에 연결(익명 → 구글)

### 홈 화면 위젯 (3차: 2칸 · 한 달 먼저, 1칸 · 7일은 그다음) — 시안: design/ui-widgets.png (참고: 보내준 "한 달 / 1일 / 7일 위젯" 화면)
#### 위젯 4종
- [ ] 1칸: 오늘 날짜·요일 + 근무 동그라미 + 메모 1줄
- [ ] 2칸: 오늘 + 내일 나란히 (+ 다음 알람 시각 한 줄)
- [ ] 7일: 오늘부터 7일 (또는 "요일 고정"이면 이번 주 일~토)
- [ ] 한 달: 달력 전체 + 메모, 공휴일 이름, 오늘 테두리, ‹ › 달 넘기기, 톱니(위젯 설정)
#### 위젯마다 설정 화면 (위에 미리보기, 아래 설정, 맨 아래 "위젯 사용" 버튼)
- [ ] 배경 투명도 슬라이더, 배경 색 (흰색 / 검정 / 다크 모드 따라가기)
- [ ] 메모 크기 · 날짜·요일 크기 · 근무 크기 (1 / 2 / 3)
- [ ] 한 달: 날짜 구분선 보이기/감추기, 6주 고정, 메모 표시, 대근 표시, 음력 표시, 변경 근무 강조
- [ ] 7일: 요일 고정
#### 동작

- [ ] 위젯의 날짜를 누르면 앱이 그 날짜 화면으로 열림
- [ ] 앱에서 근무·메모를 바꾸면 위젯 바로 갱신, 자정에 자동으로 날짜 넘김 (새로고침 버튼은 빼기)
