## 개인 메모 / 가족 메모 구분 — 시안: design/ui-memo.png (구조), design/ui-memo-color.png (색)

- [ ] 설정 > "메모 색"에서 가족 메모 색·개인 메모 색을 바꿀 수 있게 (근무타입 색 고르기와 같은 팔레트, 미리보기, 기본값으로 되돌리기)

- [ ] 내가 쓴 가족 메모만 "나만 보기"로 되돌릴 수 있음, 남이 쓴 가족 메모는 수정·전환 불가(호스트는 삭제만)

## 백업: 구글 드라이브 (사용자 본인 드라이브의 앱 전용 숨김 폴더)
- [ ] 구글 로그인 때 "드라이브 저장 허용"(drive.appdata) 함께 받기 → 같은 계정이면 새 폰에서 바로 복원
- [ ] 백업은 **2개만 유지**: 최신 + 직전 1개 (새로 백업하면 가장 오래된 것 자동 삭제), 옵션 없음
      · 실수로 지운 상태가 자동 백업으로 덮이는 것 대비 → 복원 화면에 "직전 백업으로 복원"도 표시
- [ ] 자동 백업: 앱에서 데이터가 바뀌고 하루 1번 (와이파이·인터넷 있을 때), "지금 백업하기" 버튼
- [ ] 복원 화면: 백업 날짜·근무·메모 개수 보여주고 복원 (복원 전 확인 창), 복원은 전부 무료 (광고 없음)
- [ ] 내용: 개인 메모·알람·설정·근무타입 + 근무표 전체 사본 (가족 공유 데이터는 Firebase 에도 따로 있음)
- [ ] 안드로이드 기본 자동 백업(allowBackup)도 유지 → 폰 교체 때 한 번 더 안전망
- [ ] 기존 "백업 파일 만들기/불러오기"(파일 공유)는 고급 기능으로 남김

## 가족 초대 방식 — 시안: design/ui-invite.png
- [ ] 설정 › 가족 연결 (호스트): 가족 목록(호칭·마지막 확인 시각·권한), 남은 자리 "가족 2/3명", [＋ 가족 초대하기], 공유 설정(근무표 공유, 가족 메모 알림)
- [ ] 가족 초대하기: 호칭 입력, 권한 선택(메모·요청 보내기 / 보기만) → 8자리 코드(헷갈리는 문자 제외, XXXX-XXXX), 7일 유효, QR 코드
      · 카카오톡으로 보내기(공유 시트) · 링크 복사 · 코드 다시 만들기(이전 코드 무효)
      · 초대 링크를 누르면 앱이 열리고 코드 자동 입력 (앱 없으면 설치 안내 페이지)
- [ ] 가족 폰 첫 화면: "내 근무표 만들기" / "초대 코드가 있어요" 두 갈래
- [ ] 코드 입력: 8칸 + 붙여넣기 → 확인되면 "○○님의 근무표 · 4조2교대 C조 · 가족 N명" + 7일 미리보기 → 내 호칭 → 참여하기
      · 틀린 코드 / 만료 / 자리 없음 안내, 여러 번 틀리면 잠시 대기
