# 경쟁 앱 비교 — "교대타임" (io.rocketview.shiftworkercalendar)

> 근거: 사용자가 준 APK(base.apk)의 **권한 · 화면 이름 · 문자열 자원**만 읽음(실행 · 화면 확인 · 코드 복사 안 함). 실제 화면과 다를 수 있음. 버전 미확인.

## 그 앱에서 확인된 기능
- **회사 선택 → 근무표 자동 반영** ("재직중인 회사를 선택하면 근무표가 자동으로 반영", 근무표 최신버전 업데이트 시 메모 · OT · 알람 유지, 회사 검색/직접입력, 근무조 선택)
- **근무 타입별 알람** (알람 반복 · 스누즈 · 배터리 최적화 제외 안내)
- **홈 화면 위젯 여러 종류**: 1일 · 2일 · 3일 · 7일 달력, 한 달(유료), 동료 근무 4조 · 8조, 위젯 글씨 색 · 투명도 · 메모 표시
- **급여 · OT 계산** (고정 월급여, 급여 추가, 예상 급여, 계산 단위)
- 표시 옵션: **음력 · 주차(주휴일) · 시작 요일 · 메모 3줄 · 근무 표시** (이 중 다수가 유료)
- **구글 캘린더 연동** (구글 캘린더 일정을 앱에서 확인, 캘린더 일정 만들기)
- **회원가입/로그인**(구글 · 페이스북 · 이메일 · 전화) + 근무표 온라인 백업 · 공유(별명), 동기화 주기, 구매 복원
- 휴가 종류 다양(공가 · 대휴 · 법휴 · 보건 · 청원 · 하계…), **매월 반복 입력**, 동료 근무(조별)
- **광고**(AdMob + 페이스북 Audience Network) + **광고 제거 · 한 달 위젯 · 메모 3줄 등 유료 구매**

## 우리 앱과 비교
| | 교대타임 | 언제쉬어 (v0.28) |
|---|---|---|
| 핵심 | 개인 근무표 · 회사별 자동 근무표 · 위젯 | **가족이 함께 보는 근무표** (요청 · 메모 · 알림) |
| 가족 | 없음(근무표 공유 수준) | 공유 달력 · 휴 요청/수락 · 가족 메모 · 푸시 · 소식 띠 |
| 시작 | 회원가입/로그인 필요한 기능 많음 | 로그인 없이 바로(구글은 선택) |
| 광고 · 결제 | 광고 + 기능 유료 잠금 | 광고 없음(출시 때 결정), 기본 기능 모두 무료 |
| 위젯 | **여러 종류 있음** | 시안만(3차 예정) |
| 회사 자동 근무표 | **있음** | 없음(직접 · 프리셋) |
| 음력 · 주차 · 시작요일 | 있음(유료) | 없음 |
| 급여 · OT | 있음 | 부가 기능으로 단순 |
| 구글 캘린더 | 연동 있음 | 계획(기기 캘린더 내보내기 먼저) |
| 스티커 · 약 알림 | 없음 | **있음** |
| 내 상태(자는 중 등) · 응원 | 없음 | **있음** |
| 이미지 공유 · 드라이브 백업 | 근무표 온라인 공유 | 달력 이미지 · 구글 드라이브 백업 |
| 다크 모드 · 화면 모드 | 확인 못 함 | 라이트 · 다크 · 시스템 |
| 권한 · 개인정보 | 넓음(계정 목록 · 설치 · 다른 앱 위에 표시 · 외부 저장소 · 광고 SDK 2종) | 좁음(알림 · 알람 · 드라이브 백업) |
| 기술 | 오래된 구조(구형 지원 라이브러리 · 큰 용량 약 31MB) | 가벼운 웹뷰 + 서버(가족 기능) |

## 배울 점(우선순위 제안)
1. **위젯**(사람들이 가장 자주 보는 곳) — 이미 3차 예정, 올리기
2. **음력 · 주차 · 시작 요일** — 작고 요청 많은 옵션, 무료로 (시작 요일은 3차에 예정)
3. **회사 선택 → 근무표 자동**은 큰 장점이나 회사 정보를 계속 모아야 함 → 먼저 "근무표 코드 공유"(TODO 나중에)로 작게 시작
4. **구글/삼성 캘린더 연동** — 내보내기 먼저
5. 급여 · OT는 필요한 사람이 많으니 부가 기능 안에서 천천히 키우기

## 우리가 지킬 강점
- **가족** (이 앱만의 이유), 로그인 없이 시작, 광고 · 결제 잠금 없음(정하기 전까지), 좁은 권한, 스티커 · 약 · 내 상태

# 경쟁 앱 비교 2 — "교대웨이브" (com.shiftwave.app, v1.7.2)

> 근거: 사용자가 준 APK 묶음의 **권한 · 위젯 이름 · 화면 문구(글자 자원)** 만 읽음. 코드 · 회사 목록 · 이미지는 복사하지 않음. 실제 화면과 다를 수 있음.

## 확인된 것
- **웹 화면 + 캡슐 앱**(React 번들, 우리와 같은 계열). 용량 큼(약 25MB). **로그인 · 회원가입 없음, 데이터는 기기 안에만**(개발자 서버로 안 보냄), 광고(AdMob) + **프리미엄 = 달력 배경 이미지**(결제는 "연동 준비 중" 문구).
- **탭**: 캘린더 · 팀(팀 전체 근무 한눈에) · 친구(친구를 추가해 서로 다른 패턴 비교, 서버 없이 기기 안) · 급여 · 알람
- **회사 · 팀 선택**으로 근무표 자동(교통공사 · 소방본부 · 경찰 · 대기업 공장 · 병원 등 수십 곳 내장) + 직접 입력(기준일 · 반복 패턴 · 조 구성) + 일반 프리셋(주야휴, 당직-비번 등)
- **급여 계산기가 정교**: 시급/월급, 야간 · 연장 · 휴일 가산, 세금 · 4대보험 공제, 인적공제, 급여 정산 기간, 급여 명세서, 환산 시급, 급여일 알림
- **알람**: "강력한 알람" / "간단한 알림", 급여일 · 메모 · 커스텀 알림, **알림 진단 화면**(권한 상태 · 배터리 최적화 경고 · 예약 목록 · 예약 다시 생성 · 알림 통계)
- **메모**: 하루 메모 · 아이콘 **5개**, 메모 모아보기 · 검색, 글자 크기 · 굵기, 표시 방식(셀 안 글자/아이콘 빼기), **앱 켤 때 "오늘 메모" 바텀시트**
- 화면: **테마 5종**(다크네이비 · 미드나잇 · 소프트블루 · 웜그레이 · 포그그린) + 배경 이미지(프리미엄) + 색상 관리 + **연간 보기** + 이미지 공유("깔끔 공유모드", 팀 · 회사명 빼기)
- **위젯 6종**(2x1 · 1x2 · 2일 · 14일 · 한 달 · 기본), 백업은 **파일**(.shiftwave) 저장 · 불러오기

## 교대웨이브 강점 / 단점
- 강점: 급여 계산, 위젯, 회사 · 팀 내장 목록, 친구 비교, 알림 진단, 메모 5개 · 모아보기, 연간 보기, 테마 · 배경, **계정 없이 기기 안 저장**(개인정보 인상 좋음)
- 단점: **가족 기능 · 요청 · 푸시 없음**(서버 없음), 스티커 · 약 · 내 상태 · 응원 없음, 백업이 수동 파일(폰을 바꾸면 파일을 옮겨야 함), 구글 연동 · 캘린더 연동 없음, 결제 미완, 광고

## 두 앱 모두에서 배울 점 (새로 나온 것)
1. **알림 진단 화면**: 권한 상태 · 배터리 최적화 · "예약된 알람 목록" · "예약 다시 만들기" → 알람이 안 울렸다는 문의를 사용자가 스스로 해결 (우리는 권한 안내만 있음)
2. **급여 계산 정교화**: 가산율 · 공제 · 정산 기간 · 명세서 — 근무자 수요가 큼 (우리 "근무 통계 · 수당" 부가 기능을 키울 후보)
3. **수익은 기능 잠금보다 "꾸미기"(배경 · 테마)**가 덜 거슬림 — 교대타임(기능 유료) 과 대비되는 좋은 예
4. **연간 보기**, **메모 모아보기 · 검색**, **앱 켤 때 오늘 메모**
5. **기관 · 회사별 프리셋**은 우리가 사용자 공유(근무표 코드)로 직접 모음
