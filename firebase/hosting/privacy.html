언제쉬어는 기본적으로 모든 정보를 이 폰 안에만 저장해요. 가족 연결이나 구글 드라이브 백업을 직접 켰을 때만 해당 정보가 구글 서버로 가요. 광고나 분석 도구는 쓰지 않아요.

언제쉬어(이하 "앱")는 교대근무자의 근무표 · 알람 · 가족 공유를 돕는 안드로이드 앱이에요. 앱을 운영하는 "언제쉬어 운영팀"(이하 "운영팀")은 이용자의 개인정보를 소중히 여기며, 아래와 같이 처리해요.

3. 구글 드라이브 백업 (선택)

백업을 직접 켜면 내 구글 드라이브의 "앱 전용 숨김 폴더"에 백업 파일이 저장돼요. 이 폴더는 이 앱만 열 수 있고, 운영팀을 포함해 다른 사람은 볼 수 없어요. 백업 파일에는 위 1번의 정보가 들어 있어요.

4. 인터넷으로 받아 오는 정보

공휴일 목록(공공 정보)을 하루 한 번 내려받아요. 이때 사용자 정보는 보내지 않아요. 다만 일반적인 인터넷 접속처럼 기기의 IP 주소가 상대 서버에 보일 수 있어요.

6. 보관 기간과 지우는 방법

  • 이 폰의 정보: 앱을 지우거나 "내 데이터 모두 지우기"를 할 때까지.
  • 서버의 정보: 가족방을 없애거나, 가족방에서 나가거나, "내 데이터 모두 지우기"를 할 때까지. "내 데이터 모두 지우기"(앱 › 설정)를 하면 서버의 내 정보와 로그인 계정까지 함께 지워져요. 가족방을 만든 사람이 지우면 가족방이 없어지고 가족은 가족방에서 나가져요. 초대 코드는 7일이 지나면 쓸 수 없어요.
  • 앱을 이미 지운 경우: 삭제 안내 페이지의 방법으로 요청해 주세요.
  • 구글 드라이브 백업 파일: 이용자 본인의 드라이브에 있어서 구글 드라이브 설정 › 앱 관리에서 직접 지울 수 있어요.

이용자는 언제든지 자신의 정보를 보고, 고치고, 지우고, 처리를 멈춰 달라고 요청할 수 있어요. 앱 안에서 직접 하거나(설정 › 내 데이터 모두 지우기 / 설정 › 가족 연결), 아래 문의 메일로 요청해 주세요. 요청은 지체 없이, 늦어도 10일 안에 처리하고 결과를 알려요.

10. 안전하게 지키기 위한 조치
