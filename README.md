# 언제쉬어

교대근무 가족이 함께 보는 근무표 + 근무에 맞춰 울리는 알람 (안드로이드 앱).
화면은 `app/src/main/assets/index.html`(WebView)이 그리고, 알람·백업·공유는 안드로이드(Kotlin)가 맡습니다.

- 패키지 이름: `com.eonjeswieo.app`
- 만들 것 목록: `docs/TODO.md` · 가족 공유(Firebase) 설계: `docs/firebase-design.md` · 시안 그림: `design/`

## 주요 기능 (1차)
- 처음 시작 설정: 근무 형태(4조2교대 등) → 오늘 근무 → 미리보기 → 출근 알람
- 근무일정 달력: 연속 근무 띠, 공휴일·대체공휴일·임시공휴일(매일 자동 갱신), 회사 휴무일 🏢
- 상단: 🗒 월 포스트잇(할 일·메모) · D-day · 오늘 · 🔔 가족 소식
- 날짜 메모: ♥ 가족 메모 / 🔒 나만 보는 메모, 키보드 바로 위 입력창, 길게 눌러 바꾸기·옮기기·삭제
- 근무타입 직접 만들기(글자·이름·색·쉬는 날), 동료근무 표(내 조 강조, 조별 근무 맞추기)
- 알람: 근무에 맞춰서만, 전날/당일/다음날, 한 번만, 소리·진동·무음, 알람마다 볼륨, 점점 커지는 소리, 알람음 선택, 다시 울림 간격·횟수
- 백업: 구글 드라이브(최신 + 직전 2개) / 파일
- 더 보기: 통계·수당, 달력 이미지 공유, 메모 색, 글자 크기, 문의, 개인정보처리방침, 데이터 지우기
- 가족 연결: 지금은 한 폰 안 "가족 보기(체험)", 실제 두 폰 연결은 2차(Firebase)

## APK 받는 법
1. GitHub 저장소 **Actions** 탭 → 가장 최근 **APK 빌드** → 아래 **Artifacts** 의 `eonjeswieo-apk` 다운로드
2. 압축을 풀어 `app-debug.apk` 를 폰에 설치 ("출처를 알 수 없는 앱 설치" 허용)

APK 는 저장소의 고정 시험 키(`keystore/test.keystore`)로 서명돼서, 새 APK 를 덮어 설치해도 데이터가 그대로 남습니다.
(스토어 출시용 키는 따로 만들어 GitHub Secrets 로 넣습니다)

## 준비하면 켜지는 것
### 공휴일 자동 갱신
1. 공공데이터포털(data.go.kr)에서 "한국천문연구원 특일 정보" 활용 신청 → 인증키(일반 인증키) 받기
2. GitHub 저장소 Settings › Secrets and variables › Actions › New secret: 이름 `KASI_KEY`, 값 = 인증키
3. 매일 새벽 `data/holidays.json` 이 갱신되고, 앱이 하루 한 번 받아 갑니다. (키가 없으면 앱 안 규칙으로 계산)

### 구글 드라이브 백업
1. Google Cloud 콘솔(나중에 Firebase 와 같은 프로젝트) › API 및 서비스 › **Google Drive API 사용**
2. OAuth 동의 화면 만들기 (테스트 단계에서는 "테스트 사용자"에 본인 구글 계정 추가)
3. 사용자 인증 정보 › OAuth 클라이언트 ID › **Android**: 패키지 `com.eonjeswieo.app`, SHA-1 `7D:CB:75:02:CD:EB:37:95:30:52:DB:FA:EB:F4:6B:80:C2:A3:9D:BD`
4. 앱 › 더 보기 › 백업 · 복원 › "구글 계정 연결하고 백업하기"

## 알람이 안 울리거나 늦으면
- 더 보기 › 알람이 잘 울리게 에서 꺼진 권한을 켜 주세요.
- 삼성/샤오미 등은 설정 › 앱 › 언제쉬어 › 배터리를 "제한 없음"으로.
- 알람 소리는 "알람 볼륨"을 따릅니다.
