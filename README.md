# 교대달력 (ShiftCal)

교대근무자를 위한 근무 달력 + 근무 연동 알람 안드로이드 앱입니다.
화면은 `app/src/main/assets/index.html`(WebView)이 그리고, 알람은 안드로이드 `AlarmManager`가 울립니다.

## 주요 기능
- 근무 패턴(주·야·휴…) 자동 달력, 날짜별 근무 변경·메모, 한국 공휴일·대체공휴일 (2026~2030)
- **근무 연동 알람**: "주간 근무 날 05:50" 처럼 근무에 맞춰서만 울림, 전날 알람, 소리/진동 선택, 5분 뒤 다시 울림
- 동료근무 표: 내 근무 패턴을 기준으로 A~D조 근무 계산 (설정에서 내 조 선택)
- 근무 통계(대근·연차·교육) + 대근 시급을 넣으면 예상 수당 계산
- 가족(게스트) 모드 흐름 체험: 가족 메모, 근무 변경 요청 → 수락/거절 → 근무표 적용
- 달력 화면을 이미지로 카카오톡 등에 공유
- 데이터 백업 파일 만들기 / 불러오기

## APK 받는 법 (Android Studio 없이)
1. GitHub 저장소의 **Actions** 탭 → 가장 최근 **APK 빌드** 실행을 엽니다.
2. 아래 **Artifacts** 의 `shiftcal-debug-apk` 를 내려받아 압축을 풀면 `app-debug.apk` 가 나옵니다.
3. 폰으로 옮겨 설치합니다. ("출처를 알 수 없는 앱 설치" 허용 필요)

## Android Studio 로 실행
이 저장소 폴더를 그대로 **Open** 하고 ▶ 실행하면 됩니다. (manifest·gradle 설정이 다 들어 있어요)

## 처음 실행하면
- "알림 허용" 창이 뜨면 허용하세요.
- 알람 탭 위쪽에 분홍 안내(정확한 알람 권한, 잠금화면 표시 권한 등)가 보이면 눌러서 켜주세요.

## 알람 시험하는 법
1. 알람 탭에서 + 를 눌러 2~3분 뒤 시각으로 만들고, 근무에 반복 = "매일" 로 저장합니다.
2. 앱을 최근 앱 목록에서 밀어서 완전히 종료합니다.
3. 시각이 되면 소리·진동과 함께 "끄기 / 5분 뒤 다시 울림" 화면이 떠야 합니다.

## 알람이 안 울리거나 늦으면
- 삼성/샤오미 등은 설정 > 앱 > 교대달력 > 배터리 를 "제한 없음"으로 바꿔주세요.
- 알람 소리는 "알람 볼륨"을 따릅니다.
- 앱을 두 달 넘게 안 열면 알람 목록이 끊깁니다. 앱을 열면 다시 채워져요.

## 아직 예시(가짜)인 부분
- 두 폰 사이 실시간 가족 공유(초대 코드·동기화) — 서버(Firebase 등)가 필요합니다. 지금은 한 폰에서 호스트/게스트 모드를 바꿔가며 흐름만 체험합니다.
- 보상형 광고·구독 결제 — AdMob / Google Play 결제를 붙여야 합니다.
